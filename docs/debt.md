# Open technical debt

Open findings, checked again on 2026-11-08; fixed findings and those of the toolkit moved to barrierkit are not listed. Rows F-xx come from the 2026-11-14 performance audit: read from the code, not measured with a profiler. Missing features live in [`roadmap.md`](roadmap.md#not-in-a-block-yet). The 2026-11-03 audit that found most of them is in git history (`git show 7fa3d19:docs/audit-2026-11-03.md`).

| S-01 | Smithay `65aa86fa`, `wayland/shell/xdg/mod.rs` (`PopupSurface::pre_commit_hook`) | `ERROR surface missing from known popups` when closing a GTK popover.
